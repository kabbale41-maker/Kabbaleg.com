KABBALEG.COM STARTER WEBSITE

Files:
- index.html: page content and structure
- styles.css: responsive visual design
- script.js: mobile navigation and current copyright year

Preview:
Open index.html in a modern browser.

Publish:
Upload all three website files to your web host's public web directory (often public_html).
Connect the domain kabbaleg.com through your domain registrar/hosting provider.
Before publishing, replace the sample email address hello@kabbaleg.com with your real contact address,
and customize the text to match your actual services. This starter site does not include a backend,
user accounts, or a working contact form.
